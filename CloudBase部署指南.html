1 注册腾讯云账号 & 开通 CloudBase
  1. 访问 腾讯云官网，注册并完成实名认证
  2. 进入 CloudBase 控制台
  3. 点击「新建环境」，填写环境名称（如 faq-cqust）
  4. 计费方式选择「按量计费」免费额度
  5. 创建完成后，记下环境 ID（格式如 cloud1-abc123def）
免费额度：CloudBase 按量计费提供免费额度，包含 CDN 流量 5GB/月、云函数调用 4万次/月、静态存储 5GB，对本项目完全够用。
2 安装 CloudBase CLI 并登录

在项目根目录打开终端，执行以下命令：

# 安装 CloudBase CLI（如已安装可跳过）
npm install -g @cloudbase/cli

# 登录腾讯云（会自动打开浏览器授权）
tcb login
注意：如果浏览器没有自动打开，复制终端输出的 URL 到浏览器手动打开。授权完成后终端会显示登录成功。
3 配置项目文件

需要修改 两个文件，将 your-env-id 替换为你的实际环境 ID：

① cloudbaserc.json - CloudBase 部署配置

{
  "envId": "cloud1-abc123def",  // ← 替换为你的环境 ID
  ...
}

② .env.cloudbase - 前端构建环境变量

VITE_API_BASE=https://cloud1-abc123def.service.tcloudbasegateway.com  # ← 替换
VITE_BASE_URL=/
API 地址说明：.tcloudbasegateway.com 域名是 CloudBase 云接入网关地址，{envId}.service.tcloudbasegateway.com 即为你的专属 API 入口。
4 部署云函数

在项目根目录执行：

# 部署 api 云函数到 CloudBase
tcb fn deploy api --path cloudfunctions/api -e "你的环境ID"

部署成功后，终端会显示类似 ✓ 函数 [api] 部署成功 的提示。

重要：部署后必须配置云函数环境变量，否则无法连接 Redis 数据库！

配置环境变量（二选一）：

方法 A - 控制台配置（推荐）：

  1. 进入 CloudBase 控制台 → 「云函数」→ 找到 api 函数
  2. 点击「配置」→「环境变量」，添加以下变量：
变量名值说明
KV_REST_API_URLhttps://willing-tiger-165042.upstash.ioUpstash Redis 地址
KV_REST_API_TOKENgQAAAAAAAoSyAA...（你的 token）Redis 访问令牌
ADMIN_PASSWORDadmin123管理员密码（可自定义）

方法 B - 命令行配置：

tcb fn config set KV_REST_API_URL "https://willing-tiger-165042.upstash.io" -e "你的环境ID" -n api
tcb fn config set KV_REST_API_TOKEN "你的Redis Token" -e "你的环境ID" -n api
tcb fn config set ADMIN_PASSWORD "admin123" -e "你的环境ID" -n api
5 开启 HTTP 访问（云接入）

云函数默认只能通过 SDK 调用，需要开启 HTTP 访问才能让前端通过 URL 调用 API：

  1. 进入 CloudBase 控制台 → 「云函数」→ 找到 api 函数
  2. 点击「触发器」→「创建触发器」
  3. 触发器类型选择「HTTP 触发」
  4. 路径填写 /api（重要！）
  5. 方法选择 ALL 或勾选 GET, POST, PUT, DELETE, OPTIONS
  6. 点击保存
验证：触发器创建后，浏览器访问 https://{envId}.service.tcloudbasegateway.com/api/faq，应返回 JSON 格式的 FAQ 数据（如果 Redis 中已有数据）。
6 构建并部署前端 
# 构建（使用 .env.cloudbase 中的环境变量）
npm run build:cloudbase

# 部署到 CloudBase 静态托管
tcb hosting deploy dist -e "你的环境ID"

部署成功后，前端访问地址为：

https://{envId}.tcloudbaseapp.com
例如：如果环境 ID 是 cloud1-abc123def，则访问地址为 https://cloud1-abc123def.tcloudbaseapp.com
7 初始化 FAQ 数据（如需）

如果 Upstash Redis 中已有数据（从 Vercel 部署时迁移），可跳过此步。

如果需要重新初始化，使用以下命令将 src/data/faq.json 的数据写入：

# 替换 {envId} 为你的环境 ID
curl -X POST https://{envId}.service.tcloudbasegateway.com/api/init \
  -H "Content-Type: application/json" \
  -d @src/data/faq.json
数据兼容：Upstash Redis 中的数据与 Vercel 部署时完全相同，云函数使用相同的 Redis 连接，无需重新导入数据。
8 验证部署
  1. 访问 https://{envId}.tcloudbaseapp.com，应看到问答库首页
  2. 检查 FAQ 列表是否正常加载（数据从 Redis 获取）
  3. 测试搜索功能和分类筛选
  4. 点击右下角管理入口，输入管理员密码登录
  5. 测试编辑、删除、置顶等功能
完成！部署成功后，访问者无需任何特殊工具即可通过浏览器直接访问网站，国内访问速度优于 Vercel。
一键部署（跳过分步操作）

如果你已配置好 cloudbaserc.json 和 .env.cloudbase，可以直接运行：

# 安装云函数依赖
cd cloudfunctions/api; npm install; cd ../..

# 部署云函数
tcb fn deploy api --path cloudfunctions/api

# 构建前端
npm run build:cloudbase

# 部署前端
tcb hosting deploy dist

然后记得去控制台配置云函数环境变量和 HTTP 触发器。

常见问题

Q: 部署后页面空白 / API 报错？

检查云函数环境变量是否正确配置（KV_REST_API_URL、KV_REST_API_TOKEN）。在控制台「云函数」→「api」→「日志」中查看错误信息。

Q: API 返回 404？

确认 HTTP 触发器路径设置为 /api，且方法包含 GET/POST/PUT/DELETE/OPTIONS。

Q: 前端能打开但数据加载失败？

检查 .env.cloudbase 中的 VITE_API_BASE 是否正确填写了环境 ID。重新 npm run build:cloudbase 后再次部署。

Q: 云函数超时？

FAQ 数据量较大时，Redis 读写可能较慢。在控制台将云函数超时时间从默认 3 秒改为 10 秒。

Q: 如何绑定自定义域名？

CloudBase 控制台 → 「静态网站托管」→「域名管理」→ 添加自定义域名，按提示添加 CNAME 解析即可。
